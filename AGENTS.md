# Regras do Projeto — CRM Águia das Promos

Ao finalizar qualquer ajuste, correção ou nova funcionalidade neste repositório:
1. Executar a validação necessária (`./vendor/bin/phpunit` e `npm run build` quando houver alterações de frontend/views).
2. Adicionar os arquivos criados/alterados com `git add` e criar o commit com mensagem descritiva (`feat(...)`, `fix(...)`, etc.).
3. Enviar automaticamente o commit para o GitHub com `git push` quando o remoto `origin` estiver configurado e acessível.
